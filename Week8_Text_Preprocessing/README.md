# Week 8 – Text Preprocessing using NLP

## Objective
To implement common text preprocessing techniques used in Natural Language Processing.

## Techniques Implemented
1. Stop word removal
2. Removing punctuation marks
3. Stemming
4. Lemmatization

## Input
Two paragraphs containing multiple punctuation marks such as:
., : ; ! ?

## Tools Used
- Python
- NLTK library
- PyCharm
- GitHub

## Steps Performed
- Tokenization of text
- Removal of punctuation characters
- Removal of stop words
- Stemming using PorterStemmer
- Lemmatization using WordNetLemmatizer
