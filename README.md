## Week 4 – Real-World Data Analysis (Air Quality Dataset)

### Objective
To apply data science techniques to a real-world, large-scale dataset related to air pollution and public health, demonstrating structured data analysis and analytical reasoning.

### Dataset
City-level daily air quality data from India, sourced from Kaggle, including:
- PM2.5, PM10
- NO, NO2, NOx, NH3
- CO, SO2, O3
- Benzene, Toluene, Xylene
- AQI and AQI categories

### Key Steps Performed
- Data loading and schema inspection
- Handling real-world missing values
- Feature engineering (time-based features, AQI severity encoding)
- City-level aggregation
- Insight-driven data visualization

### Visual Outputs
- AQI severity distribution
- Yearly AQI trend
- Top polluted cities by average AQI
- Monthly AQI patterns

All plots are saved in the `outputs/figures` directory.

### Skills Demonstrated
- Real-world data cleaning strategies
- Feature engineering
- Time-series reasoning
- Data visualization and storytelling
- Professional project structuring
