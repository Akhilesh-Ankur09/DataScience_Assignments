# Week 7 – K-Means Clustering

## Objective
To implement K-Means clustering on an unlabelled dataset to perform customer segmentation.

## Dataset
Mall Customers Dataset (Kaggle)

The dataset contains customer demographic and spending-related features and is suitable for unsupervised learning.

## Approach
- Data loading and exploration
- Feature selection
- Feature scaling
- Elbow method to determine optimal clusters
- K-Means clustering
- Cluster visualization and interpretation

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab Notebook
- GitHub

## Output
Customer segments are visualized based on annual income and spending score.
